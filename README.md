# Mini store app
Katalog Film / Menampilkan daftar produk/film dari Fake Store API, lengkap dengan fitur filter kategori, sortir harga, dan keranjang belanja (shopping cart).  Konsep Utama: Manipulasi array tingkat lanjut, manajemen state keranjang (add/remove/total price), modularisasi kode (ES6 Modules).
